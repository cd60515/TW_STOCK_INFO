# 隔日沖進場訊號推播

每個開盤日中午 12:00(週一至週五,盤中),掃描台股即時報價,找出「現在可以考慮買進、
明天伺機賣出」的隔日沖候選股,寄到你的 Gmail。跟 `daytrade_notifier`(當沖版,同樣
中午推播,但邏輯完全不同)是各自獨立的機制,兩者互不影響。

## 為什麼一定要用「即時」報價,不能用收盤後的資料

隔日沖的操作是「今天買、明天賣」。如果程式收盤後才告訴你今天誰漲停,那時候市場已經
關門,你根本買不到;而且隔天開盤照大戶的劇本通常是主力倒貨的時間點,這時候才進場,
你會變成被割的那一方,而不是跟著大戶賺價差的那一方。

所以要在「還買得到」的時候(盤中)就知道現在誰在噴出,只能用即時報價,不能等收盤後
才結算。程式邏輯:

1. 先用前一個已結算交易日的全市場收盤行情,取成交值排行前 150 大個股,當作「今天要
   盯盤的候選池」(只是拿來決定要查誰的即時報價,不是判斷依據本身)
2. 對候選池逐一查詢 TWSE 即時報價 API,取得執行當下(中午 12:00)的成交價與累積成交量
3. 用「現在」的即時漲幅、即時成交量重新篩選:
   - 即時漲幅 ≥ 5%
   - 即時累積成交量 ≥ 300 張
   - 標記「接近漲停」(即時漲幅 ≥ 9%):這種可能已經追價買不到,下單前務必看委買委賣
4. 依即時漲幅排序,取前 10 檔,對照證交所官方「上市公司產業別」資料標上每檔的產業別,
   並統計候選名單中同產業出現 2 檔以上的族群(產業聚焦),附上新聞搜尋連結供你自行
   覆核利多/利空

以上門檻皆可用環境變數覆寫(`POOL_SIZE`、`MIN_CHANGE_PCT`、`MIN_VOLUME_LOTS`、
`NEAR_LIMIT_PCT`、`TOP_N`)。

判斷完全依據執行當下的即時數據,不依賴任何預先整理的產業/題材清單,所以每天都能
重新反映當下最熱的標的,可以無限期自動運作下去。

## 關於「產業別」與「產業聚焦」

產業別直接對照證交所官方「上市公司基本資料」開放資料(公司代號 → 產業別代碼),
是結構化資料,不需要任何 AI 判讀,穩定可靠。

「產業聚焦」是額外算出來的:如果今天的候選名單中,有 2 檔以上剛好屬於同一個產業別,
就會額外列出來——這代表可能是當下的族群輪動焦點,但這純粹是「今天這份名單剛好撞
產業」的統計結果,不是對產業趨勢的預測,樣本數也很小(通常只有 10 檔候選),請勿
過度解讀。

## 關於「利多/利空消息」

程式本身**不會**自動摘要新聞——自動化的新聞相關性判讀容易誤判,與其做一個不可靠的
摘要,不如老實給你每檔候選股的新聞搜尋連結,由你自己在下單前花 30 秒確認最新消息。

每封信也固定附上隔日沖跟單心法提醒(這是「現在買、明天賣」的短期訊號,不是長抱、
接近漲停要留意買不買得到、進場先設停損、隔天開盤 4% 分水嶺、09:00–09:30 黃金出場期)。

## 設定步驟

沿用 `daytrade_notifier` 已設定好的 GitHub Secrets(`GMAIL_USER`、`GMAIL_APP_PASSWORD`、
選用的 `MAIL_TO`),不需要另外設定。

排程已設定在 `.github/workflows/overnight-notify.yml`,目標是讓信件在台北時間週一至
週五中午 12:00 送達。實測發現 GitHub 在這個時段的 schedule 觸發平均晚了約 4.5 小時,
因此 cron 已設定為提前 4.5 小時觸發(`'30 23 * * 0-4'`)來抵銷,詳見該檔案內的註解。
若想在台股公告的平日休市日也跳過寄信,可在 `holidays.txt` 中手動加入日期,一行一個,
格式 `YYYY-MM-DD`。

### 手動測試

到 repo 的 `Actions → 隔日沖進場訊號推播 → Run workflow`,可選填 `date`(格式
YYYYMMDD)測試候選池要用哪一天的結算資料,但**即時報價一定反映執行當下的市場狀態**,
非交易時段執行會拿到上一個交易日收盤時的價格(此時漲跌幅無意義,僅能用來確認程式
本身沒有壞掉)。

### 錯誤處理

查詢 TWSE 時若遇到暫時性錯誤(例如伺服器回傳 502),程式會自動重試最多 3 次;即時報價
若只有部分批次失敗,會略過該批次、用其餘成功查到的資料照常產生候選名單,不會因為一批
查詢失敗就整次沒有結果。若重試後仍完全失敗(例如候選池本身抓不到),會改寄一封簡短的
「今日查詢失敗」通知信並附上錯誤訊息,讓你知道今天為什麼沒收到正常的候選名單,而不是
什麼都沒收到。

## 本機執行

```bash
pip install -r requirements.txt
export GMAIL_USER=your_name@gmail.com
export GMAIL_APP_PASSWORD=xxxxxxxxxxxxxxxx
python overnight_notify.py
```

## 免責聲明

本程式僅對台灣證券交易所公開即時行情資料做機械式篩選與整理,協助你依「即時漲幅、
即時成交量」等隔日沖主力典型素質快速縮小觀察範圍,**不構成任何投資建議、不保證
獲利、不保證個股籌碼結構或是否真的被隔日沖大戶鎖定**。隔日沖為高風險策略,今天買、
明天賣的過程中仍可能因隔夜消息大幅逆轉,所有交易決策與風險由使用者自行負責。
