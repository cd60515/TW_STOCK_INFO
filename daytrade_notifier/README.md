# 台股當沖觀察名單推播

每個開盤日(週一至週五)中午 12:00(台北時間),自動整理一份台股當沖觀察名單,寄到你的 Gmail。

## 篩選邏輯依據的當沖心法

- **流動性優先**:先取「成交值排行前 20 大」個股,避免冷門股當沖沖不掉。
- **成交量門檻**:成交量需 ≥ 2,000 張,買賣才順。
- **成交值門檻**:成交值需 ≥ 5 億元(反映熱門度與法人/主力關注)。
- **要有波動空間**:當日振幅(最高−最低)/前一日收盤 需 ≥ 3%,太悶的盤沒有沖的利潤空間。
- **避開鎖死風險**:排除漲跌幅接近漲跌停(≥ 9%)的個股,避免鎖死無法沖銷。

以上門檻皆可用環境變數覆寫(`MIN_VOLUME_LOTS`、`MIN_TURNOVER_YI`、`MIN_RANGE_PCT`、
`MAX_CHANGE_PCT`、`TOP_N`、`CANDIDATE_POOL`)。

每封信也會固定附上當沖交易紀律提醒(進場時段、每日觀察檔數上限、停損紀律、當沖資格覆核)。

**資料來源**為證交所(TWSE)每日收盤後結算的公開資訊,因此中午執行時反映的是「最近一個
已結算交易日」的數據,用途是提供觀察名單的機械式篩選參考,**不是即時報價**,也**不構成
投資建議**。實際下單前務必自行至券商系統確認報價與個股當沖資格。

## 設定步驟

### 1. 建立 Gmail 應用程式密碼

1. 前往你的 Google 帳戶,先開啟「兩步驟驗證」(2-Step Verification)。
2. 前往 https://myaccount.google.com/apppasswords 建立一組「應用程式密碼」(App Password)。
3. 複製產生的 16 碼密碼(注意:不是你的 Gmail 登入密碼)。

### 2. 在 GitHub Repo 設定 Secrets

到本 repo 的 `Settings → Secrets and variables → Actions → New repository secret`,新增:

| Secret 名稱 | 說明 |
| --- | --- |
| `GMAIL_USER` | 你的 Gmail 帳號,例如 `your_name@gmail.com` |
| `GMAIL_APP_PASSWORD` | 上一步產生的 16 碼應用程式密碼 |
| `MAIL_TO` | (選用)收件信箱,可與寄件者相同或填多個(逗號分隔)。留空則預設寄給自己 |

### 3. 排程

`.github/workflows/daytrade-notify.yml` 目標是讓信件在台北時間週一至週五中午 12:00 送達。

實測發現 GitHub 在 `04:00 UTC`(對應台北中午 12:00)這個整點附近的 schedule 觸發,平均會
晚大約 4.5 小時(常見的熱門排程時段,佇列較長)。因此目前 cron 設定為 `'30 23 * * 0-4'`
(UTC 週日至週四 23:30,對應台北週一至週五 07:30),刻意提前 4.5 小時抵銷這個延遲,讓信件
實際送達時間落在中午附近。若之後 GitHub 的延遲狀況改變,可能需要重新校正這個補償值——
可以觀察 Actions 頁面裡 schedule 觸發的 `created_at` 時間,跟目標的 12:00 比對落差。

GitHub Actions 的排程觸發**本來就非絕對準時**(尖峰時段可能再多延遲數分鐘到數小時),且若
repo 超過 60 天無任何 commit 活動,排程會被 GitHub 自動停用,需要手動到 Actions 頁面重新
啟用一次。

若想在台股公告的平日休市日(例如春節、颱風假)也跳過寄信,可在 `holidays.txt` 中手動加入
日期,一行一個,格式 `YYYY-MM-DD`。

### 4. 手動測試

到 repo 的 `Actions → 台股當沖觀察名單推播 → Run workflow` 可手動觸發一次,確認信件能
正常寄達。

### 錯誤處理

查詢 TWSE 時若遇到暫時性錯誤(例如伺服器回傳 502),程式會自動重試最多 3 次。若重試後
仍失敗,會改寄一封簡短的「今日查詢失敗」通知信並附上錯誤訊息,讓你知道今天為什麼沒收到
正常的觀察名單,而不是什麼都沒收到。

## 本機執行

```bash
pip install -r requirements.txt
export GMAIL_USER=your_name@gmail.com
export GMAIL_APP_PASSWORD=xxxxxxxxxxxxxxxx
python daytrade_notify.py
```

## 免責聲明

本程式僅對台灣證券交易所公開行情資料做機械式篩選與整理,協助你依「流動性、成交值、
波動度」等當沖常見心法快速縮小觀察範圍,**不構成任何投資建議、不保證獲利、不保證個股
於篩選當下可現股當沖或未被列為處置股/注意股**。所有交易決策與風險由使用者自行負責。
